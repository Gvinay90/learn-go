# Go Learning Hub

An interactive reference for learning Go, built with Next.js and deployed on Vercel.

## What's Inside

- **Data Structures in Go** — Arrays, slices, hash maps, stacks, queues, linked lists, trees, heaps, tries, and graphs with idiomatic Go implementations
- **Concurrency** — Goroutines, channels, WaitGroups, mutexes, and common concurrency patterns
- **System Design** — Rate limiting, pub/sub, connection pooling, and distributed concepts
- **Go vs Other Languages** — Side-by-side comparisons with Java, Python, and C++
- **Standard Library** — Key packages with usage examples
- **Interview Patterns** — Common DSA patterns and Go-idiomatic solutions

## Live Demo

Deployed on Vercel: [https://learn-go-gvinay90.vercel.app](https://learn-go-gvinay90.vercel.app)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- [Next.js 15](https://nextjs.org/) — React framework
